# Static Page Block Builder – Beta 34

## هدف
افزودن یک ویرایشگر محتوای ساختاریافته و امن به صفحات ثابت، بدون اجرای HTML خام یا JavaScript و بدون وابستگی به یک قالب مشخص.

## انواع بلوک در نسخه فعلی
- `heading`: عنوان بخش
- `paragraph`: پاراگراف متنی با حفظ شکست خط
- `notice`: کادر اطلاع‌رسانی

حداکثر ۸ بلوک در هر صفحه. ترتیب بلوک‌ها همان ترتیب slotهای فرم است. هر بلوک متن fa، ku و en دارد؛ در صورت خالی بودن ترجمه ku یا en، متن فارسی جایگزین می‌شود.

## مدل داده
Migration شماره `000023` ستون nullable JSON با نام `content_blocks` به `static_pages` اضافه می‌کند. هر بلوک به این شکل مفهومی ذخیره می‌شود:

- `type`: یکی از heading، paragraph یا notice
- `text.fa`
- `text.ku`
- `text.en`

داده‌های قدیمی بدون `content_blocks` همچنان با فیلد body قبلی نمایش داده می‌شوند؛ بنابراین مهاجرت داده‌ای لازم نیست.

## امنیت و اعتبارسنجی
- فهرست مجاز نوع بلوک allowlist است.
- حداکثر ۸ بلوک و حداکثر ۵۰۰۰ کاراکتر برای هر زبان.
- بلوک بدون نوع یا متن فارسی ذخیره نمی‌شود.
- خروجی Blade با escaping عادی نمایش داده می‌شود؛ HTML و اسکریپت اجرا نمی‌شوند.
- هیچ Widget، iframe، URL یا کد سفارشی در این نسخه پذیرفته نمی‌شود.

## سازگاری
فیلد body فعلی حفظ شده و به‌عنوان متن مقدماتی صفحه نمایش داده می‌شود. صفحات قبلی با بلوک خالی بدون تغییر کار می‌کنند. این schema مستقل از Theme است و Theme فقط ظاهر سه نوع بلوک را کنترل می‌کند.

## محدودیت‌های آگاهانه
این نسخه هنوز Drag & Drop، WYSIWYG، ستون‌بندی چندستونه، تصویر درون‌متنی، CTA، پیش‌نمایش زنده و Dynamic Data Binding ندارد. این قابلیت‌ها نباید با افزودن HTML خام به فرم پیاده‌سازی شوند؛ در مراحل بعد باید به‌صورت بلوک‌های نوع‌دار و با قراردادهای مجوز و اعتبارسنجی اضافه شوند.
