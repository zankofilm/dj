# احراز هویت مشتری و حساب کاربری – بتا ۳۴

## امکانات
- ثبت‌نام با نام، ایمیل یکتا و گذرواژه تأییدشده
- حداقل گذرواژه ۱۰ کاراکتری شامل حروف و اعداد
- ورود با ایمیل و گذرواژه و گزینه مرا به خاطر بسپار
- خروج امن با invalidate کردن Session و چرخش CSRF token
- محدودسازی تلاش ورود به ۵ درخواست در دقیقه و ثبت‌نام به ۳ درخواست در ۱۰ دقیقه
- جلوگیری از ورود حساب‌هایی که status آن‌ها active نیست
- داشبورد حساب با خلاصه سفارش‌ها و صفحه‌بندی تاریخچه
- نمایش اطلاعات پایه حساب و جزئیات سفارش و اقلام فروشنده‌ها

## مسیرها
- GET `/login` و POST `/login`
- GET `/register` و POST `/register`
- POST `/logout`
- GET `/account`
- GET `/account/orders/{publicId}`

## کنترل دسترسی
صفحات حساب و جزئیات سفارش زیر middleware احراز هویت هستند. همه queryهای سفارش با شناسه کاربر جاری محدود شده‌اند؛ دانستن UUID سفارش کاربر دیگر برای مشاهده آن کافی نیست.

## محدودیت‌های شناخته‌شده
- تأیید ایمیل و بازیابی گذرواژه هنوز پیاده‌سازی نشده‌اند.
- فرم ویرایش پروفایل و تغییر گذرواژه هنوز وجود ندارد.
- زبان متن فرم‌های ورود و ثبت‌نام فعلاً فارسی است؛ پوسته و جهت صفحه با locale هماهنگ می‌شود.
- درگاه پرداخت واقعی همچنان به Adapter رسمی و پیکربندی امن نیاز دارد.
- تست HTTP انتهابه‌انتها با دیتابیس MySQL در این محیط اجرا نشده است.

## استقرار
Migration جدید لازم نیست؛ از جدول users و password_reset_tokens موجود استفاده می‌شود.
