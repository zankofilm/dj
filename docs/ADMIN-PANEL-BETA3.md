# پنل مدیریت بازارگاه – نسخه ۱.۰.۰-beta.3

## ماژول‌های افزوده‌شده
- داشبورد مدیریتی با شمارنده کاربران، فروشندگان، محصولات و سفارش‌ها
- نمایش پرونده‌های اخیر فروشندگان، محصولات اخیر و رویدادهای حسابرسی
- فهرست کاربران با جست‌وجوی نام/ایمیل، نمایش نقش‌ها و تغییر وضعیت
- فهرست کاتالوگ با فیلتر وضعیت و جست‌وجوی slug
- تغییر وضعیت محصول با ثبت رویداد حسابرسی
- پوسته مدیریتی سفید و بنفش، RTL برای fa و ku و واکنش‌گرا برای موبایل
- نمایش لینک ماژول‌ها بر اساس Permission

## مجوزها
- `admin.dashboard.view` و `admin.access`
- `users.manage`
- `sellers.review`
- `catalog.manage`

مجوزهای جدید در AccessControlSeeder ثبت می‌شوند و نقش super-admin همه مجوزهای ثبت‌شده را دریافت می‌کند.

## محدودیت‌های این نسخه
- ماژول سفارش‌ها فقط در داشبورد نمایش خلاصه دارد؛ صفحه مدیریت و عملیات سفارش هنوز تکمیل نشده است.
- مدیریت مالی، تسویه، بازپرداخت، صفحات CMS، قالب و افزونه هنوز در پنل فعال نشده‌اند.
- تغییر وضعیت محصول فقط workflow ابتدایی moderation است؛ قواعد کامل مالکیت فکری، کاتالوگ مشترک، شکایت و اعتراض در این صفحه پیاده نشده‌اند.
- تغییر وضعیت کاربر فقط status را عوض می‌کند؛ ابطال نشست‌ها، قفل ورود، MFA و گردش‌کار اعتراض هنوز لازم‌اند.
- صفحه فروشندگان از کنترلر موجود استفاده می‌کند؛ تطبیق ظاهری و آزمون permission باید روی runtime بررسی شود.
- تست Feature و اجرای واقعی Laravel در این محیط انجام نشده است.
