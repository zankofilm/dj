# ثبت‌نام موبایلی با کد پیامکی – بتا ۳۶

## جریان ثبت‌نام
1. مشتری شماره موبایل را وارد می‌کند.
2. شماره به قالب E.164 نرمال می‌شود؛ شماره‌های ایرانی 09... به +989... تبدیل می‌شوند. ارقام فارسی و عربی نیز پشتیبانی می‌شوند.
3. کد شش‌رقمی تصادفی تولید و فقط هش آن ذخیره می‌شود.
4. کد از طریق SMS Gateway ارسال می‌شود.
5. مشتری کد را در صفحه تأیید وارد می‌کند.
6. پس از تأیید، فرم تکمیل نام و گذرواژه نمایش داده می‌شود.
7. حساب با شماره تأییدشده ساخته و کاربر وارد حساب می‌شود.

## کنترل‌های امنیتی
- اعتبار کد: ۵ دقیقه
- حداکثر تلاش: ۵ بار
- فاصله ارسال مجدد: ۶۰ ثانیه
- سقف ارسال: ۵ پیامک در ساعت برای هر شماره
- ذخیره هش کد و مصرف یک‌باره پس از تأیید
- محدودسازی Routeها با throttle
- عدم افشای مستقیم وجود یا عدم وجود شماره ثبت‌شده در پاسخ درخواست کد
- ورود با موبایل و گذرواژه؛ ورود ایمیلی برای حساب‌های قدیمی حفظ شده است.

## پیکربندی پیامک
در `.env` یا Environment Variables هاست:
- `SMS_DRIVER=http`
- `SMS_HTTP_ENDPOINT=https://...`
- `SMS_HTTP_TOKEN=...`
- `SMS_SENDER=...` (اختیاری)
- `SMS_TIMEOUT=10`

درخواست HTTP با Bearer Token و JSON شامل `to`, `message`, `sender` ارسال می‌شود. Adapter عمومی است؛ قبل از فعال‌سازی production باید endpoint و ساختار payload با مستندات پنل پیامکی انتخاب‌شده تطبیق داده شود.

برای توسعه محلی می‌توان `SMS_DRIVER=log` گذاشت؛ این روش پیامک واقعی نمی‌فرستد و در production عمداً مسدود است.

## محدودیت‌ها
