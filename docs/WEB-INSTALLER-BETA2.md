# نصب‌گر تحت وب فارسی – بتا ۲

## آنچه اضافه شده
- مسیر `/setup` برای نمایش فرم نصب فارسی
- بررسی اولیه PHP و افزونه‌ها و دسترسی نوشتن پوشه‌ها
- دریافت نام سایت، URL، مشخصات MySQL و حساب مدیر
- توکن یک‌بارمصرف نشست و محافظت CSRF
- محدودیت تلاش نصب
- ذخیره اتمیک تنظیمات محیط در `.env`
- اجرای Migration و Seeder و اتصال نقش super-admin
- ایجاد `storage/app/installed.lock` پس از نصب موفق
- غیرفعال شدن مسیر نصب پس از ایجاد قفل

## استفاده
1. فایل Release کامل Laravel را روی هاست قرار دهید؛ Document Root باید به `public/` اشاره کند.
2. `.env` و دسترسی‌های محدود storage و bootstrap/cache را آماده کنید.
3. آدرس `https://domain.example/setup` را باز کنید.
4. اطلاعات دیتابیس و مدیر اصلی را وارد کنید.
5. بعد از نصب موفق، مسیر setup باید 404 بدهد.

## محدودیت‌ها و هشدارها
- این نسخه بتا است و روی cPanel/DirectAdmin واقعی آزمایش نشده.
- فرم فقط زمانی کار می‌کند که Composer dependencies (`vendor/`) نصب شده باشند.
- این نصب‌گر فایل `.env` را تغییر می‌دهد؛ اگر میزبان اجازه نوشتن ندهد نصب متوقف می‌شود.
- پیش از اجرا، دیتابیس باید خالی یا مخصوص این نصب باشد؛ اجرای migration روی دیتابیس دارای داده تضمین نشده است.
- خطاهای migration پس از شکست ممکن است جداول نیمه‌ساخته باقی بگذارند؛ قبل از تلاش مجدد باید وضعیت دیتابیس بررسی شود.
- این نسخه هنوز صفحه تنظیمات سه‌زبانه، نصب افزونه/قالب، wizard ارتقا و بازیابی پشتیبان ندارد.
- هیچ درگاه پرداخت یا شرکت حمل‌ونقل واقعی فعال نیست.

## اصلاح حین بررسی نحوی
در بررسی PHP، نوع بازگشتی رابطه موجود در `ProductVariant` و escape مسیر کنترلرها در Route اصلاح شد. بررسی نحوی همه فایل‌های PHP باید در هر Build اجرا شود.

در بازبینی دوم، escapeهای دوتایی باقی‌مانده در فایل‌های PHP مربوط به Webhook، PaymentService و فهرست Providerها نیز اصلاح شدند. این اصلاحات فقط خطای نحوی را برطرف می‌کنند و جای آزمون Runtime را نمی‌گیرند.
