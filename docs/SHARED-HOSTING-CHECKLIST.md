# Shared Hosting Readiness Checklist

- [ ] Supported PHP version available
- [ ] Required PHP extensions enabled
- [ ] MySQL/MariaDB version verified
- [ ] Document root can target `public/`
- [ ] `.env` and source are outside public web root
- [ ] HTTPS certificate active
- [ ] Cron available
- [ ] Storage symlink or safe public-media strategy available
- [ ] Upload and post size limits verified
- [ ] PHP memory and execution limits verified
- [ ] Backup export and restore tested
- [ ] SSH/Composer availability checked, or dependencies built in CI
- [ ] Outbound HTTPS requests allowed for payment and shipping integrations
