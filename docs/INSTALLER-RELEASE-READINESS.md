# نصب‌کننده – بتا ۱۰: پایداری ادامه نصب و آزمون صفحه

## اصلاحات
- حفظ `APP_KEY` قبلی در ادامه نصب نیمه‌تمام، در صورت وجود کلید معتبر در `.env`
- الزام تطابق ایمیل مدیر، نام فروشگاه و URL با وضعیت ذخیره‌شده در نصب نیمه‌تمام
- اصلاح لینک موفقیت نصب برای نصب‌کننده ریشه به `./`
- افزودن Smoke Test مستقل برای پاسخ GET صفحه فارسی نصب بدون نیاز به Composer

## آزمون
اسکریپت `scripts/smoke-test-installer.sh` با PHP CLI و curl صفحه `setup.php` را از طریق سرور داخلی PHP باز می‌کند و وجود عنوان و بخش‌های اصلی فرم را بررسی می‌کند.

این تست فقط نمایش صفحه را می‌سنجد؛ نه نصب دیتابیس، نه اجرای Migration و نه ورود مدیر.

## محدودیت
- `vendor` در این محیط ساخته نشده است.
- نصب واقعی MySQL و اجرای Laravel هنوز انجام نشده است.
- آزمون cPanel/DirectAdmin هنوز انجام نشده است.
