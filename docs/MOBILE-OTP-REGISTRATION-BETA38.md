# ثبت‌نام موبایلی و فعال‌سازی پیامکی – بتا ۳۸

## تجربه مشتری
1. مشتری فقط شماره موبایل را وارد می‌کند.
2. سامانه شماره را به قالب E.164 نرمال می‌کند؛ ارقام فارسی و عربی نیز پذیرفته می‌شوند.
3. کد یک‌بارمصرف شش‌رقمی ارسال می‌شود.
4. مشتری کد را در صفحه تأیید وارد می‌کند.
5. پس از تأیید، مشتری نام و گذرواژه را تکمیل می‌کند.
6. حساب ساخته و فعال می‌شود و مشتری وارد حساب کاربری می‌شود.

ایمیل برای ثبت‌نام مشتری اجباری نیست. ورود حساب‌های قدیمی با ایمیل حفظ شده و ورود کاربران جدید با موبایل و گذرواژه انجام می‌شود.

## سیاست OTP
- طول کد: ۶ رقم
- عمر کد: ۳۰۰ ثانیه
- فاصله ارسال مجدد: ۶۰ ثانیه
- حداکثر تلاش برای هر کد: ۵
- حداکثر ارسال برای هر شماره و هدف: ۵ پیام در ساعت
- ذخیره کد به‌صورت Hash؛ کد خام در دیتابیس نگهداری نمی‌شود.
- کد پس از استفاده مصرف‌شده می‌شود و دوباره قابل استفاده نیست.
- برای شماره‌های از قبل ثبت‌شده، پاسخ عمومی داده می‌شود تا وجود حساب افشا نشود.
- درایور log فقط در محیط غیرتولیدی مجاز است.

## درگاه پیامک
سه حالت وجود دارد:

### Kavenegar (پیشنهاد پیش‌فرض برای شماره‌های ایران)
در فایل `.env` هاست:

```dotenv
SMS_DRIVER=kavenegar
SMS_TIMEOUT=10
KAVENEGAR_API_KEY=کلید_API_پنل
KAVENEGAR_SENDER=شماره_ارسال_اختیاری
```

در پنل Kavenegar باید حساب فعال و اعتبار کافی داشته باشید. کلید API را فقط در فایل تنظیمات خصوصی هاست نگه دارید؛ آن را در کد، مرورگر یا چت عمومی قرار ندهید.

### درگاه سفارشی HTTP
اگر ارائه‌دهنده دیگری دارید:

```dotenv
SMS_DRIVER=http
SMS_HTTP_ENDPOINT=https://provider.example/api/messages
SMS_HTTP_TOKEN=توکن_خصوصی
SMS_SENDER=شناسه_فرستنده
```

قرارداد درخواست: `POST` با HTTPS، هدر `Authorization: Bearer <token>` و بدنه JSON شامل `to`, `message`, `sender`. پاسخ HTTP موفق به‌معنای پذیرش پیام توسط درگاه است.

### توسعه محلی
`SMS_DRIVER=log` فقط خارج از production مجاز است. کد در لاگ توسعه ثبت می‌شود؛ هرگز این درایور را روی سایت عمومی فعال نکنید.

## راه‌اندازی روی هاست اشتراکی
1. پس از نصب سایت، از File Manager هاست فایل `.env` را باز کنید.
2. `SMS_DRIVER=kavenegar` را تنظیم کنید.
3. کلید API را در `KAVENEGAR_API_KEY` قرار دهید.
4. در صورت نیاز، شماره فرستنده را در `KAVENEGAR_SENDER` تنظیم کنید.
5. ذخیره کنید و یک ثبت‌نام آزمایشی با شماره‌ای که به آن دسترسی دارید انجام دهید.
6. اگر هاست قابلیت اجرای Artisan از پنل ندارد، برای تغییر env config cache از پشتیبانی هاست بخواهید cache برنامه را پاک کند؛ در بسته فعلی config cache فعال‌سازی خودکار نشده است.

## امنیت و حریم خصوصی
- کلید API فقط سمت سرور استفاده می‌شود.
- گزارش خطای ارسال پیامک فقط نوع exception و نام درایور را ثبت می‌کند؛ کلید API یا کد OTP در پیام خطا ثبت نمی‌شود.
- endpoint سفارشی فقط HTTPS پذیرفته می‌شود.
- شناسه کاربر، شماره موبایل و کد OTP در URL قرار نمی‌گیرند.

## محدودیت‌ها و معیار پذیرش
- ارسال زنده با حساب Kavenegar واقعی در این محیط آزمایش نشده؛ برای ارسال واقعی باید کلید API معتبر و اعتبار پنل تنظیم شود.
- ارسال بین‌المللی از مسیر Kavenegar در این پیاده‌سازی پشتیبانی نمی‌شود؛ شماره‌های غیرایرانی باید از درگاه HTTP سازگار استفاده کنند.
- تأیید ایمیل، ورود بدون گذرواژه با OTP، تغییر شماره موبایل و بازیابی گذرواژه پیامکی در این مرحله نیستند.
- پذیرش نهایی استقرار منوط به اجرای Migration روی MySQL هاست و دریافت واقعی پیامک است.
