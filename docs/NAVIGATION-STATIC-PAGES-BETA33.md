# مدیریت منوها و صفحات ثابت – بتا ۳۳

## منوهای قابل مدیریت
از مسیر پنل «هویت و سربرگ سایت»:
- حداکثر ۵ لینک برای Header
- حداکثر ۸ لینک برای Footer
- عنوان جداگانه برای fa، ku و en
- URL داخلی با `/` و URL خارجی فقط با `https://`
- حذف خودکار ردیف ناقص یا دارای URL نامعتبر
- ذخیره در setting با کلید `navigation` و پوشش در Snapshot تنظیمات ظاهری

## صفحات ثابت
مسیر پنل: `/admin/pages`
مجوز: `pages.publish`

امکانات:
- ایجاد، ویرایش و حذف
- وضعیت پیش‌نویس یا منتشرشده
- slug یکتا و قابل استفاده در URL
- عنوان و متن سه‌زبانه
- SEO title و description
- ثبت عملیات در AuditLog
- نمایش عمومی فقط برای صفحات منتشرشده

مسیر عمومی: `/pages/{slug}`

محتوای صفحه به‌صورت متن ساده ذخیره و با escaping نمایش داده می‌شود؛ HTML خام و اسکریپت اجرا نمی‌شود. شکست زبان‌های ku و en به محتوای فارسی fallback دارد.

## مدل داده
Migration شماره `000022` جدول `static_pages` را می‌سازد:
- slug یکتا
- translations به شکل JSON
- seo به شکل JSON
- status و published_at
- created_by و updated_by

## امنیت
- کنترل مجوز در Route و Controller
- CSRF برای فرم‌های تغییردهنده
- slug با alpha_dash و یکتایی
- محتوای عمومی escaped
- لینک‌های خارجی فقط HTTPS و لینک داخلی فقط مسیر نسبی با یک `/` ابتدایی
- AuditLog برای ایجاد، ویرایش و حذف

## محدودیت این مرحله
صفحه‌ساز بلوکی و WYSIWYG در این مرحله وجود ندارد. محتوای صفحات متنی است. مدیریت منوها به شکل فرم ردیف‌های ثابت انجام می‌شود، نه Drag & Drop. ترجمه‌های خالی ku/en به فارسی fallback می‌کنند.

## استقرار
Migration شماره `000022` باید اجرا شود. نصب و مهاجرت روی هاست اشتراکی واقعی هنوز آزمایش نشده است.
