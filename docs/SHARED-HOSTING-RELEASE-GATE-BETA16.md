# دروازه انتشار هاست اشتراکی – بتا ۱۶

## تغییرات
- بررسی افزونه‌های پایه PHP با جزئیات بیشتر (DOM، Filter، Hash، Session، PCRE و JSON)
- بررسی مجزای قابلیت نوشتن پوشه‌های storage/app، storage/framework و storage/logs
- بررسی وجود Laravel Framework در vendor، فایل `.env.example` و `public/index.php`
- شفاف‌سازی در صفحه نصب که فرایند از مرورگر انجام می‌شود و به Terminal/SSH نیاز ندارد
- مستندسازی چیدمان امن و روند File Manager برای هاست اشتراکی

## تفسیر
این بررسی‌ها فقط پیش‌نیازها را تشخیص می‌دهند. آن‌ها جایگزین تولید وابستگی‌ها، اجرای واقعی روی cPanel یا آزمون امنیتی نیستند.

## مانع اصلی
Composer در محیط ساخت در دسترس نیست و پوشه vendor تولید نشده است. تا زمان ساخت ZIP کامل در محیط دارای Composer، نصب کامل با مرورگر ممکن نیست.
