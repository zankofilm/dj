# مانع ساخت بسته نصب کامل – بتا ۱۷

در محیط فعلی PHP CLI موجود است اما Composer، `composer.lock` و پوشه `vendor/` موجود نیستند. دسترسی شبکه ابزار ساخت نیز برای دریافت امن وابستگی‌ها فراهم نیست.

بنابراین ساخت ZIP نصب کامل از این محیط ممکن نیست. ساخت vendor ساختگی یا اعلام نصب‌پذیری نادرست و ناامن خواهد بود.

برای Release نهایی باید در محیط دارای Composer 2 و PHP 8.2+:
1. lockfile کنترل‌شده تولید شود.
2. `composer install --no-dev --prefer-dist --optimize-autoloader` اجرا شود.
3. تست‌های سازگاری و امنیتی اجرا شوند.
4. ZIP شامل `vendor/`، `composer.lock` و manifest هش تولید شود.
5. نصب واقعی روی cPanel بدون SSH آزمایش شود.

Composer فقط در محیط ساخت Release اجرا می‌شود؛ کاربر نهایی برای نصب نیازی به Terminal یا SSH نخواهد داشت.
