# دروازه انتشار نسخه ۱.۰.۰

## اصلاحات این بتا
- ثبت PaymentServiceProvider و ShippingServiceProvider در Bootstrap
- اصلاح DatabaseSeeder برای استفاده از ساختار کامل حساب‌های دفتر کل
- افزودن دستور `marketplace:preflight`
- افزودن الگوی محیط مخصوص هاست اشتراکی
- تکمیل راهنمای فارسی نصب CLI و محدودیت‌های هاست اشتراکی

## موارد مسدودکننده انتشار پایدار
1. اجرای `composer install` و تست بوت برنامه روی PHP 8.2+ واقعی
2. اجرای تمام Migrationها از دیتابیس خالی و تست Upgrade از نسخه قبلی
3. رفع خطاهای احتمالی رابطه‌ها و نام ستون‌ها در مدل‌های سفارش/مرسوله/مرجوعی
4. آزمون کامل Seederها و ایجاد مدیر اصلی
5. تست‌های Feature برای ثبت سفارش، پرداخت آزمایشی، Webhook، دفتر کل، تسویه و مرجوعی
6. آزمون امنیتی CSRF، XSS، IDOR، دسترسی مدیر و فروشنده، Rate Limit و Webhook Replay
7. نصب واقعی روی cPanel و DirectAdmin
8. ساخت Release artifact شامل vendor و بررسی صحت فایل ZIP
9. نصب‌گر تحت وب فارسی با قفل یک‌بارمصرف، CSRF، rate limit و حذف/غیرفعال‌سازی قطعی پس از نصب
10. اتصال PSP و شرکت حمل فقط پس از انتخاب ارائه‌دهندگان و اجرای Sandbox

## سیاست انتشار
تا وقتی همه موارد مسدودکننده پاس نشده‌اند، نسخه فقط `beta` است و نباید برای فروش واقعی، پرداخت واقعی یا نگهداری داده حساس مشتری استفاده شود.
