# جست‌وجو، فیلتر و آرشیو دسته‌بندی – بتا ۲۶

## مسیرها
- `/` فروشگاه با جست‌وجو، فیلتر و مرتب‌سازی
- `/categories/{slug}` آرشیو دسته‌بندی با همان امکانات
- `/products/{publicId}` جزئیات محصول (از نسخه بتا ۲۵)

## قواعد نمایش
فقط محصولات active یا published، دارای published_at و متعلق به فروشنده approved در نتایج عمومی قرار می‌گیرند. این قاعده در query پایه مشترک اعمال می‌شود.

## جست‌وجوی فعلی
جست‌وجوی GET روی slug، brand_name و مقدار JSON ذخیره‌شده در translations با LIKE انجام می‌شود. ورودی محدود و escape می‌شود. این جست‌وجو نسخه اولیه و ساده است؛ موتور Full-Text، نرمال‌سازی دقیق فارسی/عربی، stemming، غلط‌یابی، autocomplete و رتبه‌بندی relevance هنوز پیاده نشده‌اند.

## فیلترها و مرتب‌سازی
- فروشنده تأییدشده
- حداقل و حداکثر قیمت بر اساس base_price_minor
- جدیدترین
- ارزان‌ترین
- گران‌ترین
- صفحه‌بندی ۲۴تایی با حفظ query string

## محدودیت‌های مهم
- قیمت‌ها در این نسخه بر اساس base_price_minor و بدون تبدیل ارز مرتب می‌شوند؛ بهتر است فروشگاه در فاز بعد فقط ارزهای یکسان را با هم مقایسه کند یا تبدیل ارز را به Price Engine بسپارد.
- min_price و max_price بر مبنای واحد خرد ذخیره‌شده‌اند، نه نمایش اعشاری محلی؛ عنوان فرم این محدودیت را توضیح می‌دهد.
- جست‌وجوی LIKE روی JSON برای داده حجیم کارایی موتور Search Architecture نهایی را ندارد.
- دسته‌بندی فعلاً یک سطح آرشیو مستقیم است؛ breadcrumb درختی و مسیر والدها بعداً تکمیل می‌شود.
- فروشندگان فهرست‌شده در فیلتر از فروشندگان approved دارای محصول منتشرشده انتخاب می‌شوند.
- تخفیف و محبوبیت تا زمان اتصال داده‌های سفارش و موتور قیمت‌گذاری نمایش داده نمی‌شوند.
